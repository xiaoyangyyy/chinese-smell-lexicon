# 中文气味词典

从公版古诗、本草和方志里抽出的气味记录。一条记录是一个气味词在一句里的一次出现。

**363,190** 条。词表收 612 个气味词，这批书里出现了 **595** 个。

| 来源 | 条数 |
| --- | ---: |
| 方志 | 106,567 |
| 本草 | 105,324 |
| 全宋诗 | 101,303 |
| 全宋词 | 22,384 |
| 全唐诗 | 22,359 |
| 元曲 | 4,700 |
| 五代诗词 | 553 |

诗来自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 的《全唐诗》《全宋诗》《全宋词》《元曲》和五代词，MIT 分发的结构化文本。本草是 40 种古典本草，文本来自 [TCM-Ancient-Books](https://github.com/xiaopangxia/TCM-Ancient-Books)。方志是 198 种地方志，文本来自 [daizhigev20](https://github.com/garychowcmu/daizhigev20) 的史藏／地理。诗句和古籍本身是公有领域。

字段：气味词、类别、对象、地方、季节、感官、原文、出处、时代、来源。

地方、季节、感官只在这句里写到了才填，没有写到就空着，不推测。方志书名能看出州县的，地方用书名里的地名。原文保持语料里的字，短于四个字的不收。气味词用简体。

同一首诗如果《全唐诗》和《全宋诗》都收了，只留《全唐诗》。方志的时代只在书名写了年号时填写，例如乾隆、康熙、嘉靖。书名没有年号的通志不推测朝代，时代留空。

类别有：花香、气味、食物、香料、草木、水土、腐朽、药香、烟火、腥膻。

`data/气味词典.csv` 是全表。`data/抽查1000.csv` 是随机抽查的 1000 条。
